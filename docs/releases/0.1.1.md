# OrbitShift 0.1.1

**See your current language and switch it from the menu bar.** This update adds country flags and direct input-source selection to OrbitShift for macOS.

## What's new

- A compact country flag replaces the globe in the menu bar, using the standard macOS status-item size. A globe remains the fallback for sources without a country.
- Click the flag to choose any enabled macOS input source. Languages appear first, and the current layout has a checkmark.
- The flag and selection stay in sync when you change languages in another app or the system menu, including while OrbitShift runs in the background.
- Settings, pause/resume and quit remain below the language list.

## Download or update

Requires **macOS 14+**. **OrbitShift-0.1.1.zip** contains one app for **Apple Silicon and Intel**. Existing users can check for updates in OrbitShift's settings. For a manual installation, quit OrbitShift, unzip the download and replace **OrbitShift.app** in **Applications**. Quit OrbitShift Dev before running the regular app.

This release is still ad-hoc signed, without Apple Developer ID or notarization. If macOS blocks the first launch and you trust the download, follow [Apple's instructions](https://support.apple.com/en-us/102445). The update archive and feed are signed with OrbitShift's existing Sparkle key.

After an update, macOS may require a fresh Accessibility grant. If the enabled entry is not recognized, remove it from **System Settings → Privacy & Security → Accessibility**, add the installed **OrbitShift.app**, and enable it again. Your language order and other settings are preserved by the app.

## По-русски

**Текущий язык теперь виден по флагу, а раскладку можно выбрать прямо из строки меню.**

- Вместо глобуса — компактный флаг страны, размером с обычный системный значок. Для источников без определённой страны остаётся глобус.
- В выпадающем меню сначала идут языки; текущий отмечен галочкой. Нажмите на нужную раскладку, чтобы переключиться.
- Флаг обновляется и при смене языка через системное меню или другое приложение, даже когда OrbitShift работает в фоне.
- Настройки, пауза и выход расположены ниже списка языков.

Нужна **macOS 14+**. Архив **OrbitShift-0.1.1.zip** подходит для **Apple Silicon и Intel**. Обновление можно проверить в настройках OrbitShift или установить вручную, заменив приложение в **Программах** после его завершения. Перед запуском обычной версии закройте OrbitShift Dev.

Сертификат Apple Developer ID и нотариализация пока не настроены; обновления подписываются прежним ключом Sparkle. При блокировке первого запуска используйте [инструкцию Apple](https://support.apple.com/ru-ru/102445).

После замены приложения macOS может потребовать повторно выдать **Универсальный доступ**. Если включённый переключатель не помогает, удалите старую запись и добавьте установленный **OrbitShift.app** заново. Порядок языков и остальные настройки приложение сохраняет.
