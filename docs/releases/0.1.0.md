# OrbitShift 0.1.0

**Your languages. One key.** The first public release of OrbitShift, a native macOS keyboard layout and input-language switcher.

## What it does

- Switches to the next input source when you release Fn / Globe or another assigned key on its own.
- Supports left/right Shift, Control, Option and Command, plus F13–F19.
- Lets you choose and reorder a cycle of macOS input sources.
- Keeps modifier combinations such as Fn + Delete from triggering a language switch.
- Provides menu bar controls, pause/resume and launch at login.
- Guides first-time keyboard permission setup and detects restored access automatically.
- Offers an English/Russian interface and signed Sparkle update checks with installation after confirmation.
- Keeps preferences locally without recording typed text or sending analytics.

## Download and first launch

Requires **macOS 14 or later**. Download **OrbitShift-0.1.0.zip** below; the same app supports **Apple Silicon and Intel**. Unzip it, move **OrbitShift.app** to **Applications**, and open it.

This release uses ad-hoc code signing. It is **not Developer ID signed or notarized by Apple**. If macOS blocks an unidentified developer, use **System Settings → Privacy & Security → Open Anyway** after trying to open it, only if you trust the download. See [Apple's guidance](https://support.apple.com/en-us/102445). Do not disable Gatekeeper.

Allow Accessibility when prompted. For Fn / Globe, set **System Settings → Keyboard → Press 🌐 key to → Do Nothing**, then choose your language order in OrbitShift.

If OrbitShift Dev is running, quit it first. Production has separate settings and permissions. Replacing this ad-hoc-signed app in the future may require renewing its Accessibility permission.

Fn availability depends on the keyboard. Composition input methods such as Japanese and Chinese are not fully validated. This is the first public version; an upgrade from an earlier public release cannot yet be verified.

## По-русски

Первый публичный релиз **OrbitShift** — переключателя раскладки для macOS. Нажмите и отпустите Fn / Globe без других клавиш, чтобы перейти к следующему языку в своём списке. Можно выбрать другую поддерживаемую клавишу, изменить порядок раскладок, включить автозапуск или поставить переключение на паузу.

Скачайте **OrbitShift-0.1.0.zip**, распакуйте и перенесите приложение в **Программы**. Нужна **macOS 14+**, поддерживаются **Apple Silicon и Intel**.

Версия пока без сертификата Apple Developer ID и нотариализации. Если macOS блокирует запуск и вы доверяете загрузке, после попытки открыть приложение подтвердите его в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Название кнопки зависит от версии macOS; [инструкция Apple](https://support.apple.com/ru-ru/102445). Gatekeeper отключать не нужно.

Разрешите **Универсальный доступ** по системному запросу. В настройках клавиатуры выберите **Нажать клавишу 🌐 для → Ничего не делать**. Если запущен OrbitShift Dev, завершите его: у обычного приложения отдельные настройки и разрешения.
