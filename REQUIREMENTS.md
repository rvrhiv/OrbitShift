# OrbitShift — требования к первой версии

Статус: требования для реализации; готового приложения пока нет.

## Цель

Нативная утилита macOS, позволяющая сразу продолжать печать на следующей раскладке после отпускания выбранной клавиши, без ожидания штатного переключателя языков.

## Требования пользователя

1. Переключать язык при отпускании клавиши.
2. По умолчанию использовать Fn / Globe, но позволять выбрать другую клавишу.
3. Поддерживать несколько языков и переключать их по кругу.
4. Поддерживать автозапуск при включении Mac.
5. После переключения стандартная иконка языка macOS должна показывать фактически используемый язык.
6. Обновляться из GitHub Releases по модели LimitRoom: автоматическая проверка, установка и перезапуск после подтверждения пользователя.

Под автозапуском понимается запуск после входа пользователя в учётную запись macOS. Утилита работает в пользовательской сессии, включая обычную работу после сна и разблокировки.

## Предлагаемый интерфейс

Одно приложение со значком в строке меню. Меню открывает настройки, позволяет временно приостановить переключение и завершить приложение.

В настройках:

- выбор клавиши с отображением текущего назначения;
- список источников ввода с добавлением, удалением из цикла и изменением порядка;
- переключатель запуска при входе;
- автоматическая проверка обновлений, ручная проверка и установка найденной версии;
- состояние необходимых системных разрешений и переход к соответствующим настройкам macOS.

Языки представлены системными источниками ввода, а не только двухбуквенными кодами: две раскладки одного языка остаются разными пунктами. В первой версии список доступных источников берётся из включённых источников macOS. Для добавления ещё не включённого языка интерфейс ведёт в настройки клавиатуры macOS, после чего обновляет список.

Предлагаемый минимальный уровень поддержки — macOS 14. Первичная проверка проводится на текущем Mac с macOS 26.6.2.

## Поведение клавиши

- Переключение выполняется ровно один раз на отпускании одиночной назначенной клавиши.
- После отпускания нет искусственного таймера ожидания или ожидания анимации.
- Если во время удержания была нажата другая клавиша, переключение отменяется для всего текущего нажатия. Например, Fn + Delete и Fn + стрелки сохраняют своё обычное поведение.
- Если на момент нажатия уже удерживается другая клавиша или модификатор, это сочетание не считается одиночным нажатием.
- Автоповтор не вызывает дополнительных переключений.
- Левая и правая клавиши-модификаторы различаются при выборе назначения.
- При изменении назначения, паузе, сне или потере обработчика события незавершённого нажатия сбрасываются, чтобы не вызвать неожиданное переключение позже.
- Для назначенной обычной клавиши нужно исключить ввод её символа. Для клавиши-модификатора нужно сохранить сочетания. Эти два режима обрабатываются отдельно.
- Конфликтующее штатное действие Fn / Globe отключается пользователем в настройке «Нажать клавишу 🌐 для…». Сам Fn как модификатор не отключается.

Точный набор поддерживаемых альтернативных клавиш и способ подавления их штатного одиночного действия фиксируются после проверки событий macOS. Неподдерживаемое назначение нельзя молча принимать.

## Цикл источников ввода

Настройки хранят упорядоченный список устойчивых идентификаторов системных источников, а не локализованные названия.

При переключении:

1. Получить фактически текущий источник macOS.
2. Сопоставить сохранённый цикл с доступными и выбираемыми источниками.
3. Выбрать следующий источник; после последнего вернуться к первому.
4. Если текущий источник не входит в цикл, перейти к первому доступному источнику из цикла.
5. При пустом списке ничего не переключать; при единственном источнике не выполнять повторное переключение на него.
6. Ошибку выбора не выдавать за успех и не продвигать отдельный внутренний индекс.

Изменения через системное меню, другую программу или настройки macOS обновляют состояние OrbitShift. Удалённые или временно недоступные источники пропускаются без сбоя; пользователь видит их состояние в настройках.

## Стандартный индикатор macOS

Источник правды — выбранный источник ввода macOS. Предлагаемый основной путь переключения — `TISSelectInputSource`; для чтения состояния — `TISCopyCurrentKeyboardInputSource`. Приложение слушает уведомления об изменении текущего и доступных источников ввода.

Обновление собственного значка приложения не считается выполнением требования о стандартной иконке. Для приёмки должны одновременно совпадать:

- фактически выбранный источник macOS;
- стандартный индикатор языка в строке меню;
- символы, вводимые в активном приложении сразу после переключения.

Прямой вызов API сам по себе не доказывает, что все три состояния согласованы на конкретной версии macOS. Это проверяется в TextEdit, браузере и редакторе кода. Если обнаружится рассинхронизация, исправляется взаимодействие с системой; имитация правильной подписи в собственном меню недостаточна.

Сложные методы ввода с композицией, например японский или китайский, требуют отдельной проверки. Поддержка нескольких обычных раскладок не должна выдаваться за подтверждение работы всех методов ввода.

## Техническая основа

Одно нативное приложение на Swift: SwiftUI для настроек, AppKit для жизненного цикла и строки меню, Text Input Source Services для раскладок, ServiceManagement для автозапуска, Sparkle 2 для обновлений.

Алгоритм одиночного нажатия и алгоритм выбора следующего источника отделены от системных адаптеров, чтобы их можно было проверить детерминированно.

Транспорт клавиатурных событий выбирается по результатам проверки Fn с отключённым штатным действием. Для обычных клавиш рассматривается `CGEventTap`; если Fn не приходит через него, понадобится адаптер IOKit HID. Два адаптера не должны вызывать двойное переключение от одного физического нажатия.

## Обновления из GitHub Releases

Использовать Sparkle 2 и публичные релизы `rvrhiv/OrbitShift`, как в LimitRoom. Вход пользователя в GitHub для обновления не нужен.

Поведение приложения:

- Автоматически проверять наличие новой стабильной версии; в настройках можно отключить проверки.
- Предоставить действие «Проверить обновления» и отображать доступную версию.
- После подтверждения пользователя скачать обновление, проверить подпись, установить его и перезапустить приложение. Автоматическая проверка не означает перезапуск во время работы без подтверждения.
- Показывать ход обновления и понятную ошибку при сбое. При отказе проверки подписи текущая установленная версия сохраняется.
- После обновления сохранять назначенную клавишу, состав и порядок языков, состояние автозапуска и настройки обновлений.
- В локальных Dev-сборках отключать установку официальных обновлений.

Публикация:

- Отдельный вручную запускаемый GitHub Actions workflow Release собирает утверждённую версию из `main` и публикует GitHub Release.
- Релиз содержит архив приложения, подписанный `appcast.xml`, описание изменений и `SHA256SUMS`.
- Планируемый адрес ленты: `https://github.com/rvrhiv/OrbitShift/releases/latest/download/appcast.xml`. До первого релиза этот канал ещё не существует.
- Версия приложения и номер сборки увеличиваются; уже опубликованные версии не переиспользуются.
- Архив и лента проверяются Sparkle до установки. Для OrbitShift используется собственная пара ключей Ed25519; закрытый ключ хранится вне репозитория и доступен только этапу подписания релиза.

## Разрешения и жизненный цикл

Потребность в Accessibility и/или Input Monitoring зависит от выбранных системных адаптеров. Приложение показывает фактическое состояние разрешений и не сообщает о готовности, пока необходимый обработчик не работает.

Обработка событий не должна сохранять набираемый текст. Настройки хранятся локально. Работа с источниками ввода не требует сети; сеть используется для проверки и загрузки обновлений.

После сна, переподключения клавиатуры или восстановления разрешений приложение восстанавливает обработчики и перечитывает системное состояние. Отказ автозапуска не мешает ручному запуску; переключатель в интерфейсе отражает фактический статус ServiceManagement.

## Проверка первой версии

Проверки алгоритмов: одиночное нажатие и отпускание, сочетание клавиш, уже удерживаемый модификатор, автоповтор, смена назначения, цикл из двух и трёх источников, переход через конец списка, внешний выбор источника, отсутствие доступных источников и ошибка системного выбора.

Ручная проверка на реальном Mac:

1. Fn: одиночное нажатие переключает один раз на отпускании; ввод можно продолжать сразу.
2. Fn + Delete, Fn + стрелки и Fn + функциональные клавиши не переключают язык.
3. Другая назначенная клавиша работает после перезапуска приложения и не вызывает лишнего штатного действия.
4. Цикл из трёх источников проходит в заданном порядке; порядок можно изменить.
5. Стандартный индикатор и фактический ввод совпадают в TextEdit, браузере и редакторе кода, включая быстрый набор сразу после отпускания.
6. Ручной выбор языка через macOS корректно меняет стартовую точку цикла.
7. Включённый автозапуск проверяется новым входом в учётную запись; выключенный — отсутствием запуска.
8. Сон, разблокировка и переподключение клавиатуры не приводят к зависанию или двойному переключению.
9. Отсутствие и отзыв разрешений дают понятное состояние и путь восстановления.
10. Установленная предыдущая версия обнаруживает новую стабильную версию через автоматическую и ручную проверку.
11. Подтверждённое обновление устанавливается, приложение перезапускается, клавиша, языки, их порядок и автозапуск сохраняются.
12. Отмена, отсутствие сети и неверная подпись не приводят к установке неподтверждённой версии или потере настроек.
13. Dev-сборка не заменяется официальным релизом автоматически.

Ощущение скорости проверяется по вводу, а не только по смене значка. Численные обещания задержки не публикуются до измерения на реальном оборудовании.
